# Hybrid CNN-LSTM for DDoS Detection in SDN Environments

This public repository serves as a landing page for researchers interested in accessing the dataset and supplementary materials used in our IEEE Access submission:

**"Hybrid CNN-LSTM Model for DDoS Detection and Mitigation in Software-Defined Networks"**

🔒 The dataset is not publicly uploaded here to ensure responsible sharing.
